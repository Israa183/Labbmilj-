# Labbmiljö

Detta repository innehåller dokumentationen för laborationen inom IT.

## Innehåll

Projektet innehåller dokumentation om:

- Labbmiljö och nätverk
- Linux och Windows
- Kommandoradsgenomförande
- Git och versionshantering
- AI-användning och kritisk granskning

## Fullständig dokumentation

Den fullständiga dokumentationen finns i:

[documentation.md](documentation.md)

Dokumentationen innehåller steg-för-steg-beskrivningar, använda kommandon,
nätverksinformation, Git-arbetsflöde samt AI-logg och kritisk granskning.
